# 運用と更新

## 公開
Cloudflare Pages無料枠へ既存GitHub連携で追加。公開URLが候補と違う場合は `SITE_URL` を設定しビルドし直す。既存サイトに手を加えない。
公開後、トップ・比較・計算・おまとめ・404・robots・sitemapとHTTPセキュリティヘッダーを確認する。

## 日次
公式商品ページの変更、終了した広告案件、リンク切れ、審査変化を確認する。公式照合に失敗した場合は時刻と理由を記録し、重要条件を自動公開しない。

## 週次
金利・限度額・対象年齢・対象債務、行政登録情報、広告コード・併用条件を再照合。計算テストを実行する。

## 月次
ASP別の確定成果とAdsterra収益、承認・否認率、検索流入、広告配置を評価。母数不足なら勝敗未判定とする。

## 自動実行
現在、GitHub Actionsによるpush時テストを用意。日次の公式変更監視・ChatGPTタスク・Cloudflare自動公開との接続は公開先確定後に行う。未接続の監視を稼働中と報告しない。
既存「Webサイト日次運営・検索対策」の担当・実行枠・権限は変更しない。追加する場合は既存プロンプト全体を読み、公開先と書込み権限が確認できた範囲の担当のみ追加する。

## ロールバック
Cloudflare Pagesの直前の正常デプロイへ戻す。並行して原因のcommitをrevertしmainと公開内容を一致させる。全広告停止は `content/ads.json` のenabled=falseで再ビルド。
